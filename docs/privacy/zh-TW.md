## 概述

Kano PDF Tool（以下稱「本應用程式」）由黃毓峰開發。本隱私權政策說明我們在您使用本應用程式時如何處理您的資訊。

## 資料收集

**我們不收集任何個人資料。**

本應用程式完全在您的本機裝置上運作。您開啟或編輯的所有 PDF 檔案、圖片和文件都在本機處理，絕不會上傳至任何伺服器。

## 資料儲存

所有資料都保存在您的裝置上。本應用程式可能儲存：

- 使用者偏好設定（儲存於您的裝置）
- 最近開啟的檔案清單（儲存於您的裝置）

這些資料絕不會傳輸至外部伺服器。

## 第三方服務

本應用程式不使用任何第三方分析、廣告或追蹤服務。

## 更新

本應用程式包含自動更新功能，會從 GitHub 檢查新版本。此過程僅下載更新資訊，不會收集任何個人資料。

## 政策變更

我們可能會不時更新本隱私權政策。任何變更都會在本頁面公布，並更新修訂日期。
